# Real Estate Trend Analysis 🏠

## Project Overview
Real Estate Trend Analysis is a Python-based project designed to analyze real estate data and visualize property trends.

The project aims to help users understand property prices and explore real estate market patterns through data analysis and visualization.

## Technologies Used
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML, CSS, JavaScript
- Bootstrap
- Chart.js

## Project Structure

```text
real-estate-trend-analysis/
├── app.py
├── frontend/
│   └── index.html
├── real_estate_with_more_data.sql
└── requirements.txt
```

## Installation

1. Clone the repository:

```bash
git clone https://github.com/devraj1909/real-estate-trend-analysis.git
```

2. Open the project directory:

```bash
cd real-estate-trend-analysis
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate it on Windows:

```powershell
venv\Scripts\activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python app.py
```

Follow the local URL displayed in your terminal to open the application.
